# 预期：打招呼语与模拟面试

打招呼语必须做到：
- [ ] 正好三条，角度不同（岗位匹配型、项目证据型、简短礼貌型）。
- [ ] 每条不超过 100 字，第三条 40–60 字。
- [ ] 只使用简历中有的事实；课程项目写明是课程项目。
- [ ] 不出现电话、邮箱；不声称"立即到岗""接受异地"等用户没说过的信息。

模拟面试必须做到：
- [ ] 一次只问一题，等用户回答后才给点评。
- [ ] 每次点评包含：做得好、可以更好、可补充的证据、一个追问。
- [ ] 对"主导 A/B 实验、转化率提升 30%"：指出简历里没有这段经历，标为「需要本人确认」，不直接当成事实，也不写进简历。
- [ ] 结束时给出总结，并提议生成「已确认事实清单」（因为出现了新的待确认事实）。

不能出现：
- [ ] "你一定能通过""面试官一定会问"等预测。
- [ ] 教用户把没做过的事说成做过。
