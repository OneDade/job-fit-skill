# 示例材料

这里的简历和 JD 都是虚构的，用来在不上传真实简历的情况下试用 Skill，也适合录制演示。

安装 Skill 后，把两个文件发给 Agent，然后说：

```text
分析我的简历和这个 JD，告诉我值不值得投，然后帮我生成定制简历。
```

预期表现（便于自查 Skill 是否正常工作）：

- 结论大概率是「可以投但有风险」：有运营实习和 SQL，但没有 A/B 实验和 AI 产品的直接证据。
- 「A/B 实验」应显示为「简历里没写清」，而不是被写进简历。
- 「带领 4 人小组」是课程项目，改写后不能变成工作经历或「负责产品上线」。
- 如果改写出现新的数字（例如「留存提升 20%」），Agent 必须先问你确认；样例简历里没有这类数字。
